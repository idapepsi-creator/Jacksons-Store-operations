# Jacksons Store Operations — Preview

This is a **local-only prototype**, NOT the completed secure shared employee website.

Included: Morning/Swing/Overnight tasks, initials and timestamps, day-specific schedules, editable task lists, product expiration list, four coolers (Deli, Beer Cave, Big, Small), vendor communication notes, and history.

IMPORTANT: Employee authentication, manager-only database permissions, tamper-resistant audit history, and shared syncing are **not implemented**. The manager PIN is a convenience control, not security. Do not use this preview for real staff accountability or confidential data. Firebase remains locked in production mode; no Firestore rules need to be changed for this preview.

## Upload to GitHub
Extract this ZIP in the Files app, then upload the six individual files (not the ZIP) into the root of the repository. Enable GitHub Pages under Settings → Pages → Deploy from branch → main / (root). This publishes a preview only, not a production staff system.

The sample duties are not an official Jacksons operations policy. Verify each before use.
